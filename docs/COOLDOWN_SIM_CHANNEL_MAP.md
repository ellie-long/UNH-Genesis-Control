# Simulated cool-down channel map (for review)

Generated by `python -m cooldown_sim channel-map-report` from `cooldown_sim/channel_map.yaml`. Edit the YAML, not this file.

This is a **best-effort** mapping from the LabVIEW `data_record` columns to the Genesis instrument channels. Rows marked **guess** need a lab cross-check. After a real-data run, `<run>/channel_map_check.html` overlays each recorded column on the value Genesis actually archived, so a wrong mapping shows up as a mismatch.

## Not mapped

* `T1`/`T3` target-cup thermometers: CCX placeholders in `calibration/magnet_thermometry.csv`, not read by any Genesis IOC. `T1` feeds only the target model's lattice temperature.
* Reliquefier PLC channels (`reliquefierAnalysis/data`): no Genesis IOC yet.
* Flows (including the Roots flow meters, used for boil-off), helium levels, the magnet power supply and pump temperatures: in the LabVIEW record but no Genesis IOC yet; kept in the record for future legs.

Generated by `python -m cooldown_sim channel-map-report` from `cooldown_sim/channel_map.yaml`. Edit the YAML, not this file.

This is a **best-effort** mapping from the LabVIEW `data_record` columns to the Genesis instrument channels. Rows marked **guess** need a lab cross-check. After a real-data run, `<run>/channel_map_check.html` overlays each recorded column on the value Genesis actually archived, so a wrong mapping shows up as a mismatch.
